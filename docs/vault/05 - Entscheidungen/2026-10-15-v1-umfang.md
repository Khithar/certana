# ADR: Umfang der Version 1

## Entscheidung
**Enthalten:** Root-CA offline (erzeugen/importieren/Bundle), Intermediate-CA, Profile Server/Client-Auth/S-MIME/Code-Signing, CSR-Import, Export PEM/DER/PKCS#12 + Server-Snippets, Verwaltung, Erneuerung, Widerruf, CRL-Export, Ablaufüberwachung mit Benachrichtigung, Audit-Log, Backup, UI en/de.

**Nicht enthalten (v2-Kandidaten):** OCSP-Responder (`x509-ocsp` ist WIP, Desktop-App ist kein Dauerdienst), PKCS#11/HSM/YubiKey, SQLCipher-Vollverschlüsselung, ACME-Server, Auto-Update per Installation (nur Hinweis).

## Konsequenzen
AIA-Extension trägt vorerst nur die Issuer-URL; OCSP-URL kann später ergänzt werden, ohne bestehende Zertifikate zu brechen.
